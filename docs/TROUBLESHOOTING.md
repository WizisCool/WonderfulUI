# 故障排查

本文面向已经安装 WonderfulUI 的玩家。应用版本、Windows 版本和 ACLOS 版本可以在
设置的“关于”页和问题报告中提供；不要公开真实账户 openid、完整本地路径或快传令牌。

## 启动后没有高光

WonderfulUI 当前读取 ACLOS 默认资料目录：

```text
%USERPROFILE%\AppData\Roaming\ACLOS\WonderfulDb
```

请依次确认：

1. 已安装并登录用于生成高光的腾讯 ACLOS/“无畏时刻”客户端；
2. 客户端已经在对局结束后生成过至少一个高光；
3. 高光生成完成后，回到 WonderfulUI 点击资料库刷新；
4. 如果仍然没有结果，在设置中执行一次“全量扫描”。

WonderfulUI 不提供手动选择 ACLOS 数据目录。目录不存在、为空或只包含非账户文件时，
首次使用页面会显示检测状态。

## 扫描失败或部分账户不可用

ACLOS 可能正在写入 `WonderfulDb`。先等待写入结束，再点击刷新；如果增量扫描仍未
恢复，在设置中执行“全量扫描”。全量扫描会重新解析源文件并重建 WonderfulUI 的本地
索引，不会修改 ACLOS 文件。

部分账户失败时，其他可读账户仍可能显示。详细原因写入本机日志：

```text
%LOCALAPPDATA%\wonderful-ui\logs\wonderful-ui.log
```

可以在设置 → 日志中查看最近内容，或点击“打开目录”收集日志。发送前请删去 openid、
用户名、绝对路径和不相关的原始数据。

## 视频无法播放或已经移动

WonderfulUI 使用 ACLOS 数据中的本地视频路径。它不会在应用内修改视频路径，也不会
把 NAS、移动硬盘或网络盘自动改成新位置。

- 重新挂载保存高光的磁盘、NAS 或网络位置；
- 确认视频文件仍然存在且当前账户有读取权限；
- 回到应用执行一次全量扫描；
- 若文件已被移动或删除，应用只能保留可见的对局数据，无法恢复视频。

## 快传无法访问

快传只在用户主动打开播放器中的“快传”后启动，使用临时 `22357/TCP` HTTP 服务。
二维码设备需要与电脑在同一局域网；不要把二维码链接当作公网分享链接。

请检查：

- 手机和电脑连接的是同一 Wi-Fi/VLAN，而不是访客网络；
- 路由器没有启用 AP 隔离、客户端隔离或设备间禁止访问；
- Windows 防火墙允许 `WonderfulUI Quick Share` 规则；
- 端口 `22357` 没有被其他程序占用；
- 首次修复规则时已允许一次 Windows 管理员授权。

企业组策略、显式入站阻止规则或第三方防火墙可能拒绝局域网连接，应用无法绕过这些
策略。关闭快传后临时服务会停止；防火墙规则在完整卸载前可能保留，以避免下次使用
重复授权。

## 更新失败

正式版本会从 GitHub Releases 检查更新，因此检查和下载更新需要网络。请确认浏览器
可以打开项目的 [Releases](https://github.com/WizisCool/WonderfulUI/releases) 页面，
然后在设置 → 关于点击“检查更新”。

更新使用 Windows x64 NSIS 安装包，不会变成 MSI 或便携包。网络受限、代理、GitHub
不可达或签名校验失败时，应用会保留当前版本；不要把本地私钥或完整更新日志上传到
Issue。

## 如何提交普通问题

请使用 GitHub Issue 模板，并附上：

- WonderfulUI 版本、Windows 版本和 ACLOS 版本；
- 发生问题的最短操作步骤；
- 预期行为和实际行为；
- 脱敏后的日志片段。

提交前请删除 `%USERPROFILE%`、`%LOCALAPPDATA%`、NAS 路径、openid、账户昵称、视频文件名、
二维码 URL 和令牌。安全漏洞不要公开开 Issue，遵循 [安全策略](../SECURITY.md) 的
私密报告路径。

## 卸载与本地数据

NSIS 卸载器默认保留 WonderfulUI 的本地资料库和 WebView2 用户数据。卸载确认页可以
选择删除用户资料库；应用缓存和日志可能保留。卸载器不会读取、修改或删除 ACLOS、
无畏契约、Riot 或 Vanguard 目录。完整卸载会清理 WonderfulUI 的快传防火墙规则。
